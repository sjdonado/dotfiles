# Investigation and planning

1. Resolve the exact question and applicable repository context. An explanation or planning request permits inspection, not implementation.
2. Trace ownership, callers, contracts, and relevant history. Use skills/ask/SKILL.md for a bounded question, skills/research/SKILL.md for deeper investigation, or skills/triage/SKILL.md for a ticket. Read the whole ticket including comments before relying on it.
3. Separate observations from inferences. When a load-bearing production claim can be checked through authorized sources, use skills/evidence/SKILL.md. Missing access is a gap, not proof.
4. Return a supported answer or recommendation sized to the question. If a plan was requested, describe scope, alternatives that matter, and the evidence implementation will need. Do not turn the recommendation into an edit or a PR.
