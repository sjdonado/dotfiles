Leave a demo the owner can run from the task's checkout.

- Make the relevant journey runnable and check the behavior it claims to demonstrate (principle-prove-it-works).
- Record the run command, prerequisites, limitations and any simulated behavior where the owner will find them.
- Use tests when they provide useful evidence (principle-test-agreed-decisions), without imposing production hardening on an experiment.
- Report how to try it. Publish only if requested; do not require a ledger acceptance or automatically start yolo.
