---
name: principle-decide-then-declare
description: Guidance for resolving routine decisions and asking only for consequential missing intent or authority.
---

Resolve routine reversible choices from repository evidence and existing conventions. Choose the smallest coherent option and make consequential assumptions visible without requiring a separate decision record for every edit.

Ask when the answer cannot reasonably be derived and choosing wrong would change product intent, exceed authority or cause expensive irreversible consequences. Existing authorization remains valid within its scope. A routine branch name or equivalent implementation choice does not need confirmation.

Ask the smallest useful question with enough context to answer it. Bundle related missing information when practical; do not require a fixed question template. Do not request permission to start, continue routine work or repeat an already settled decision. An unanswered required question is not approval.
