---
name: principle-delegate-down-a-tier
description: Guidance for choosing useful delegation and an appropriate model. Read when independent or parallel work could help.
---

Delegate when a separate perspective, a substantial independent workstream or a long mechanical task adds enough value to justify its context and coordination cost. Run short checks and routine edits in the current session. A step called verification does not require a subagent.

Use the least costly capable model for mechanical work; keep difficult design decisions and consequential review at a capable tier. Follow explicit project or user model preferences. Give workers bounded ownership, the necessary task context and a reminder to preserve other edits.

Delegate work, never waiting. The session that starts a long-running command owns it through completion; a watcher agent adds no evidence. Run preview servers through managed background shells, not detached processes, and confirm readiness before reporting a URL.
